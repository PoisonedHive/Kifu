# Kifu
SGF generator for Go games recorded on paper

https://poisonedhive.github.io/Kifu/kifu-digitizer.html

Tired of always having to take written kifu records and painstakingly digitize them on a seperate program?
Tired of losing where the next move was written down?
Tired of having 200+ numbers blend together on a piece of record paper?

This application might be for you!
I recommend 'installing' the website on you applications for offline use as a Progressive Web App (PWM). It's PWM ready and can be used completely offline.

1. Users are able to take a photo using their camera, or upload an image into the application. Then select your board size (9x9, 13x13, 19x19) at the top left of the page
2. After cropping it to size (optional)
3. You place the board corners (TL = Top Left, TR = Top Right, BR = Bottom Right, BL = Bottom Left)
4. Place any handicaps you might have, clear all if a mistake is made
5. Select 'Record Moves' to record the first move of the game. You can select the next player to play , and the number it counts from.
6. Fill in your game information
7. Generate SGF then Copy to Clipboard
